## Publish with GitHub Pages

1. Create a repository named `sean-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` directly into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then click **Save**.
6. Wait for deployment, then click **Visit site** on the Pages settings screen.

For a project repository named `sean-portfolio`, the expected address is:
`https://sserubiriseannelson-pixel.github.io/sean-portfolio/`

GitHub Pages can take several minutes to publish. See the official guide:
https://docs.github.com/en/pages/quickstart
