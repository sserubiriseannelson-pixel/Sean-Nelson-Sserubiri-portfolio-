# Sean Nelson Sserubiri — Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript, no build step, no dependencies.

## Files

- `index.html` — content and structure
- `style.css` — layout, typography and animation styles
- `script.js` — kinetic headline, scroll effects, marquee and the hero line-field graphic

## Updating it

- Add finished projects as new `<article class="row">` blocks in the Work section (copy the existing one and change the number, title, link and description).
- Only list tools in the Tools section that you have actually used.
- When you have a public email or LinkedIn you're happy to share, there is a commented-out spot for it in the Contact section.

## Publishing

Served with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
